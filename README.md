# hh35Tik

موقع عربي لفحص يوزرات TikTok مع كود دخول وبحث تلقائي محدود.

## التشغيل

```bash
pip install -r requirements.txt
python app.py
```

كود الدخول الافتراضي: `HH35-TIK-2026`

في Render أضف متغيرات البيئة:
- `SECRET_KEY`
- `ACCESS_CODE`

الفحص يعتمد على الصفحة العامة لـ TikTok، وقد يعرض «غير قابل للتأكيد» عند وجود حماية أو تحديد للطلبات. لا تعتبر النتيجة متاحة إلا إذا ظهرت صراحة «غير مستخدم».
